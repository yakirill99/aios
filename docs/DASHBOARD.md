# Дашборд

Веб-интерфейс к системе: NPV, состояние агентов, фонд скважин и журнал
цикла скользящего горизонта.

## Запуск

```bash
docker compose up --build
```

Открывается на <http://localhost:8000>. Без ключей, без внешней сети,
без предварительной настройки — сразу после старта видно рабочий
интерфейс на эталонном наборе из `ui/demo/`. Как только в
`~/aios-data/rolling/` появятся результаты прогона, дашборд
переключится на них сам.

Без Docker:

```bash
pip install -e .
uvicorn aios.dashboard.server:app --port 8000
```

## Два экрана

- **`/`** — сводка: NPV против планки, фонд скважин, агенты,
  ограничения, график управления. Переключатель **простой /
  продвинутый** прячет технические блоки, когда нужен только верхний
  уровень. Выбор запоминается между открытиями.
- **`/dashboard.html`** — журнал прогона: пошаговая история решений,
  сравнение NPV с базовым сценарием, таблица скважин, сырой JSON.

Данные обновляются опросом раз в 2 секунды. Если сервер недоступен, на
экране остаются последние полученные цифры и появляется
предупреждение — интерфейс не обнуляется посреди защиты.

Chart.js лежит локально в `ui/web/vendor/`. Внешних ссылок в HTML нет
ни одной, всё отрисуется на машине без интернета.

## Как это связано с расчётом

```
rolling_horizon.py ──> ~/aios-data/rolling/journal.json ──┐
probe_wells.py ─────> ~/aios-data/probes/*.csv ───────────┤
                                                          v
                                        aios.dashboard.collect
                                                          │
                          ~/aios-data/rolling/state.json <─┘
                                                          │
                                            /api/state ───┴──> дашборд
```

Связь односторонняя: дашборд знает про расчёт, расчёт про дашборд не
знает. Сервер не импортирует `scripts/` и `src/aios/`, ничего оттуда не
вызывает и подключает каталог с прогонами **только на чтение**.
Расчётные скрипты трогать не нужно.

## Файлы

```
src/aios/dashboard/
├── server.py     FastAPI: ручки API + раздача интерфейса
├── state.py      чтение rolling/ с откатом на ui/demo/
├── runner.py     запуск прогона в фоне (по AIOS_RUN_CMD)
└── collect.py    ★ переходник: вывод расчёта -> JSON для дашборда
ui/
├── web/          интерфейс: HTML, JS, Chart.js
└── demo/         эталонный набор, лежит в git
```

Фронт не собирается: обычные HTML и JS, npm и node в образе нет.
Правки видны после перезагрузки страницы.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | живость, идёт ли прогон, куда смотрит сервер |
| GET | `/api/state` | сводка для главного экрана |
| GET | `/api/journal` | журнал прогона |
| POST | `/api/run/start` | запустить прогон в фоне |
| GET | `/api/run/status` | что с фоновым процессом |
| GET | `/api/artifacts/{файл}` | `wells_schedule.inc`, `npv_claimed.txt` |

Документация: <http://localhost:8000/docs>

### Откуда данные

Ответы несут заголовок `X-Data-Source` со значением `live`, `demo` или
`mixed`, а `/api/journal` дополнительно возвращает ключ `_source` с
картой «какой раздел откуда взят»:

```json
"_source": {"config": "live", "journal": "live", "wells": "demo"}
```

Это нужно, чтобы на защите не выдать эталонный набор за результат
прогона. Живые разделы перекрывают демонстрационные по одному, поэтому
дашборд остаётся рабочим, даже когда расчёт готов наполовину.

## Сборка данных после прогона

```bash
python -m aios.dashboard.collect
```

Читает `~/aios-data/rolling/journal.json`, добирает матрицу влияния из
`~/aios-data/probes/response_matrix.csv`, достраивает разделы `wells`,
`agents`, `matrix` и пишет рядом `state.json`.

Запись атомарная — через временный файл и переименование. Без этого
дашборд может прочитать JSON на середине записи и увидеть обрывок.
Если `rolling_horizon.py` пишет журнал напрямую, стоит сделать так же.

### Что ещё не доделано в collect.py

`build_wells()` восстанавливает фонд по расписанию: какие скважины
упоминались в управляющих воздействиях и что с ними делали последним
шагом. Дебиты и обводнённость при этом нулевые — их нужно подставить
из `summary_to_csv.py`, место помечено TODO.

Это единственный файл, который придётся править при смене формата
вывода расчёта. К математике он отношения не имеет.

## Переменные окружения

Скопируйте `.env.example` в `.env`. Реальный `.env` в git не идёт.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8000` | порт на хосте |
| `AIOS_DATA_DIR` | `~/aios-data` | каталог с прогонами |
| `AIOS_RUN_CMD` | пусто | команда запуска прогона |
| `AIOS_LOG_LEVEL` | `INFO` | подробность лога |
