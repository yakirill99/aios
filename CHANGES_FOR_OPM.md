# Правки деки Model_Y для OPM Flow

Оригинал организаторов: `vendor/model/Model_Y/` — не изменяется.
Рабочая копия: `model/Model_Y_opm/`.

Дека сгенерирована в tNavigator и без правок не читается OPM Flow.
Каждая строка ниже — потенциальный источник расхождения при контрольном
пересчёте организаторов. Нужно уметь объяснить каждую.

---

## Обязательные правки (без них дека не парсится)

| Что | Где | Симптом | Почему |
|---|---|---|---|
| Блок `#if 0 ... #endif` | `MODEL_Y.DATA:31-35` | `String #if 0 not formatted as valid keyword` | препроцессор tNavigator, OPM его не знает |
| `IMPLICIT` | `MODEL_Y.DATA:29` | `Problem with keyword IMPLICIT` | ключевое слово tNavigator; OPM и так полностью неявный |

```bash
sed -i '/^#if 0/,/^#endif/d' MODEL_Y.DATA
sed -i '/^IMPLICIT/d'        MODEL_Y.DATA
```

## Косметические правки

| Что | Где | Почему |
|---|---|---|
| CRLF → LF | `MODEL_Y.DATA` | окончания строк Windows |
| Лишний `/` после `WELLDIMS` | `MODEL_Y.DATA:~46` | двойной терминатор; tNavigator прощает. **OPM тоже проглотил** — правка не была необходимой |

## Правки секции SUMMARY

| Что | Почему |
|---|---|
| Убраны `WOMT`, `WOMR` | `Unknown keyword: WOMT` — массовые векторы есть только в tNavigator |
| Убраны `WTHP`, `WEFF` | без секции VFP дают нули; в формулы ЧДД не входят |
| Убраны трассерные `WTPRAQW`, `FTPRFW` и прочие | трассеров в модели нет |
| Добавлены `WOPT`, `WOPR` | объёмные аналоги, из них считается масса |

**Пересчёт массы.** OPM выдаёт объём, методика требует тонны:

```
WOMT = WOPT × 0,833 т/м³
```

Плотность из секции `DENSITY` в `pvt.inc`: 832 и 834 кг/м³ по двум
PVT-регионам, взято среднее. Погрешность усреднения 0,12%.

## Управление записью RESTART

| Где | Было | Стало | Почему |
|---|---|---|---|
| `sch.inc:4` | `RPTRST 'BASIC=5' 'FREQ=3'` | отключён для пробных прогонов | 34 снимка по 39 МБ = 1,3 ГБ на прогон |
| прогон истории | — | `BASIC=4` (раз в год) | нужен только финальный снимок |

Физику это не меняет — только состав выходных файлов.

---

## Влияние на результат

Сверка с эталоном организаторов на периоде 2007–2015 (5 326,5 млн руб на
OPM Flow, 5 261,2 на tNavigator) дала расхождение около 1,5% после
устранения всех дефектов подготовки данных.

Организаторы указали, что расхождение между tNavigator и OPM Flow на
модели из 100 скважин за 30 лет составляет менее двух процентов — наше
значение внутри этого диапазона.

Ни одна из правок не меняет физику: убраны только конструкции,
специфичные для tNavigator, и векторы, которых OPM не поддерживает.

## Как воспроизвести рабочую копию

```bash
cp -r vendor/model/Model_Y model/Model_Y_opm
cd model/Model_Y_opm
sed -i '/^#if 0/,/^#endif/d' MODEL_Y.DATA
sed -i '/^IMPLICIT/d'        MODEL_Y.DATA
sed -i 's/\r$//'             MODEL_Y.DATA
# SUMMARY: убрать WOMT, WOMR, WTHP, WEFF, трассерные; добавить WOPT, WOPR
```

Проверка:

```bash
cd ~/aios/scripts
./smoke_test.sh                    # контур в целом
./verify_reference.sh              # сверка с эталоном
```
